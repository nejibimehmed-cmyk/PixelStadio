Pixel Studio V3 - پروژه اندروید

امکانات:
- افزودن چند تصویر و مدیریت لایه‌ها
- جابه‌جایی، تغییر ترتیب و حذف لایه
- حذف رنگ پس‌زمینه یک‌رنگ با تنظیم تلورانس (نه حذف هوشمند AI)
- فیلتر، روشنایی، کنتراست و اشباع
- قلم و پاک‌کن لمسی + ابزار انتخاب و جابه‌جایی لایه‌ها
- واترمارک متنی و افزودن لوگو
- ذخیره خودکار در حافظه مرورگر WebView و خروجی پروژه JSON
- خروجی PNG/JPG/WEBP

ساخت APK:
1) پوشه پروژه را در Android Studio باز کنید.
2) اجازه دهید Gradle Sync کامل شود.
3) از منوی Build گزینه Build Bundle(s) / APK(s) و سپس Build APK(s) را انتخاب کنید.
4) فایل APK در app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.

نیازمندی: Android Studio جدید، JDK 17 و Android SDK Platform 35.
در محیط ساخت فعلی Android SDK/Gradle نصب نیست؛ بنابراین APK کامپایل‌شده ضمیمه نشده و این فایل، سورس کامل پروژه قابل ساخت است. خروجی تصویر در نسخه اندروید با پنجره انتخاب محل ذخیره خود اندروید ذخیره می‌شود.

نکته فنی: حذف پس‌زمینه فعلی بر اساس رنگ انتخابی است و برای پس‌زمینه‌های تک‌رنگ بهتر عمل می‌کند. حذف سوژه با هوش مصنوعی به مدل/سرویس جداگانه نیاز دارد.
